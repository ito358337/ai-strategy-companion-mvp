# バックアップ: 土地活用提案・動画発信・ゆずりえ無料講座(2026年7月7日)

クロードコードとの相談で作成した資料一式のバックアップです。
相談の流れと、各フォルダの中身を記録しておきます。

## 相談の経緯(あらすじ)

1. **銀行×地主さん向け土地活用の提案**からスタート
   - 多治見近郊の工務店として、銀行(信用金庫)と連携し、地主さんに賃貸アパート・戸建賃貸による土地活用+相続対策を提案する計画
   - 重要な背景: **令和8年度税制改正「貸付用不動産の5年ルール」**(2027年以降の相続・贈与から、取得後5年以内の貸付用不動産は時価の80%評価)。ただし5年以上前から所有する土地への建築は経過措置の見込み → 「昔からの地主さんこそ早めに動くと有利」が提案のフック
   - 戦略: 資料は2種類(A=銀行向け連携企画書、B=地主様向け提案書)。入口は税理士共同の無料セミナー+相続税かんたん試算
2. **収支計画計算書(Excel)を作成**
   - 戸建賃貸版とアパート版。前提条件(黄色セル)を入力すると30年収支・相続への説明材料・金利上昇シナリオ・DSCRが自動計算
3. **動画発信(SNS自動投稿)の相談**
   - ライブ録画(15〜20分の一人しゃべり)→文字起こし→投稿文自動生成→Facebookページ・X・ワードプレスは自動投稿、noteは公式APIがないため「9割自動(貼り付けのみ手動)」
   - お客様の不安別テーマ50本と台本テンプレートを作成
4. **ゆずりえプロジェクトの無料講座化**
   - 既存資産: 水曜昼の対談動画16話(ゆずりえ)+平日朝7時のマーケティング×世界観動画(約20話)
   - 設計: 3段ロケット(毎日のSNS発信 → 無料メール講座36話・約3ヶ月 → 完走者限定説明会 → 有料会員「ゆずりえの仲間」)
   - 開始時の固定費0円の構成。次のアクションは「クロードに渡すものチェックリスト」の記入

## フォルダの中身

### 01_銀行連携_土地活用提案
- `資料A_銀行向け連携企画書_完全版ドラフト.md` — 銀行に共催を持ちかける企画書(コンプライアンス配慮の5原則入り)
- `資料B_地主様向け提案書_完全版ドラフト.md` — 地主さんに渡す本命提案書(税制改正の章・モデル試算入り)
- `セミナーチラシ_文面案.md` — 集客チラシとDM送付状の文例、キャッチコピー4案
- `社内向け解説_土地活用プロジェクトのしくみ.md` — 事務員さん向けのやさしい解説(用語集・電話対応の注意付き)
- `工務店版_土地活用提案パッケージ構成.md` / `地主向け土地活用提案書_構成テンプレート.md` — 構成の設計メモ(初期版)

### 02_収支計画Excel
- `収支計画計算書_戸建賃貸30年.xlsx` — 棟数×棟あたり家賃で入力
- `収支計画計算書_アパート30年.xlsx` — 延床坪数×坪単価、間取りタイプ別戸数×家賃で入力
- `作成プログラム_*.py` — 上記Excelを再生成・改造するためのプログラム(クロードコードで実行)
- 使い方: 「前提条件」シートの黄色セルだけ入力。DSCR 1.2以上を銀行提出の目安に

### 03_動画発信・SNS
- `動画テーマ集と台本テンプレート.md` — 不安別テーマ50本(1年分)+15〜20分の台本の型+自動投稿の設計図

### 04_ゆずりえ無料講座
- `ゆずりえ無料講座_リード獲得の仕組み設計書.md` — 無料講座→有料会員の全体設計(LP文面・メール文例・会費たたき台入り)
- `クロードに渡すものチェックリスト.md` — 次に進めるための記入式シート ★次のアクションはこれ

## 再開するときの合言葉(クロードコードへの声かけ例)

- 「バックアップフォルダの資料Bを、実案件の数字で仕上げたい」
- 「収支計画Excelを作り直したい(作成プログラムを実行して)」
- 「チェックリストの①を渡すから、講座のメール文を書き始めて」

※ 税制改正(5年ルール)の記載は2026年7月時点の公表情報に基づく。実行時は必ず税理士に最新の通達を確認すること。
