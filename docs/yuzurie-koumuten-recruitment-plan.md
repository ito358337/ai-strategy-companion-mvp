# ゆずりえプロジェクト 工務店加盟 直近2ヶ月実行計画

作成日: 2026年7月2日
目標: **毎月3社の加盟契約**(7月・8月で計6社、まず「加盟までの型」を完成させる)

---

## 1. 戦略 — この2ヶ月で何を達成するか

### 1-1. 2ヶ月のゴールは「6社」ではなく「再現できる型」

7月・8月は数を追う期間ではなく、**「接触→面談→契約→初案件」の型を完成させる期間**と位置づけます。理由:

- 月3社ペースだと年末時点で約20社。50社目標に届かせるには、秋以降に**紹介とセミナーで加速**する必要がある
- 加速の燃料は「実際に加盟して動き出した工務店の事例」。最初の6社はその事例そのものになる
- だから最初の6社は「数合わせ」ではなく、**事例として発信できる、やる気のある工務店**を選ぶ

### 1-2. 逆算ファネル(月3社に必要な数)

| 段階 | 月間必要数 | 想定転換率 |
|---|---|---|
| 加盟契約 | **3社** | — |
| 個別面談(30分オンライン/見学会) | 10社 | 面談→契約 30% |
| 反応(返信・小冊子DL・問い合わせ) | 20社 | 反応→面談 50% |
| 接触(DM+紹介+発信) | **500〜700社** | 接触→反応 3〜4% |

※ コールドDMだけだと反応率1〜2%が現実的。**紹介・既存ネットワーク経由は面談→契約が50%超**になるため、DMで数を作りつつ紹介で確度を上げる二本立てにします。

### 1-3. 攻める順番(確度の高い順)

1. **既存の縁**: 協力業者・職人ネットワーク・建材店/建材商社の営業・金融機関の取引先紹介。建材店の営業は毎日工務店を回っており、最強の紹介経路
2. **近隣エリア**: 岐阜県内→愛知・長野・三重。見学会に呼べる距離が初期は有利(多治見の実物を見せられる)
3. **DMリスト**: 全国の新築主体工務店(A案)・リフォーム/不動産兼業(B案)。工務店団体名簿・建築専門紙・Instagramで反応した工務店アカウント

## 4. 戦術の要点 — 面談→契約の3割を実現する仕掛け

### 4-1. 面談の型(30分)

1. **最初の10分は相手の話**: 新築の問い合わせ状況・リフォームの競争環境・後継者。売り込まない(ゆずりえの哲学どおり)
2. **次の10分で個別診断**: 事前に調べた「御社の市の空き家数・相場」を見せる。一般論ではなく"あなたの街の話"にした瞬間に自分事になる
3. **最後の10分で道筋**: 加盟のご案内+「次は見学会 or 個別診断の深掘り」の2択を提示。**その場で契約を迫らない**が、次の一歩は必ずその場で日程確定する

### 4-2. クロージングの3点セット

- **限定性**: 1市1社のエリア制。「御社の市を他社に案内する前に、まず御社に」は誠実かつ強力
- **安心**: 初案件90日伴走(オーナー打診・診断・企画書までエーテルが同席)。「加盟して独りにしない」
- **実証**: 多治見の実数(相談35件/2ヶ月・広告費ほぼゼロ)+8月からは1号店事例

### 4-3. 宣伝(工務店向け発信)

- Instagram/LINEで週1本は**工務店経営者向け**の投稿を混ぜる(再生現場の裏側・収支の考え方・「なぜ工務店が主役なのか」)
- セミナーは毎月開催を固定化し、DMの受け皿にする(DM→いきなり面談は腰が重くても、セミナーなら申し込みやすい)
- 9月頭にプレスリリース「地域工務店○社と『住み継ぎ』ネットワーク始動」を打つ前提で、8月中に素材(写真・数字・コメント)を集めておく

### 4-4. 体験(加盟前後で「仲間になった」と感じてもらう)

- 面談前: 個別診断シートが届く=「自分の街を調べてくれた」体験
- 面談後: 24〜48時間以内のフォロー=「対応が早い会社」体験
- 契約後: 初案件伴走+月1オンライン事例共有会=「独りにされない」体験
- 最初の6社は**創業メンバー**として名前を刻む(LP掲載・共同発信)。50社になったときの古参の誇りを最初から設計する
