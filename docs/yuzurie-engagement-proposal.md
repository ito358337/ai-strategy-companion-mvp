# ゆずりえプロジェクト 参加促進 提案書

作成日: 2026年7月2日
対象資料: 戦略設計セッション(2026/6/9)、戦略・戦術整理シート①〜③、入居者向け小冊子、工務店向けDMメール案(A案/B案)、空き家活用プラットフォーム構想

## 0. 前提の整理

### 「参加させる」相手は3者いる

ゆずりえは四方よし(入居者・大家さん・工務店・地域)の仕組みであり、「参加」の意味が相手ごとに違います。

| 参加者 | 参加の定義 | 2026年12月目標 |
|---|---|---|
| 入居者家族 | 無料相談 → 有料企画 → 入居 → 住み継ぎ | 1000家族 |
| 仲間の工務店 | 資料請求 → 30分面談 → 地域パートナー契約 → 初案件着手 | 50社 |
| 空き家オーナー | 活用相談 → 建物診断 → 物件登録(貸す決断) | 家族数に連動 |

### 逆算すると見える構造

- 1000家族 ÷ 50社 = **1社あたり20家族**。エーテル単独では不可能で、**工務店の参加が最優先のレバー**になります。
- 残り6ヶ月で50社 = **月8〜9社**の仲間入り。DM返信率1〜3%と仮定すると、月300〜900社への接触が必要です。
- 入居家族1組につき物件1軒が要るため、**オーナー参加(物件供給)が隠れたボトルネック**です。相談35件が来ても、渡せる家がなければ止まります。

### 現状の強みと詰まり(資料より)

- ✅ 広告費をかけず2ヶ月で35件以上の相談。Instagram無料投稿2日で数件の問い合わせ → **入口は機能している**
- ⚠️ 面談後、有料企画(企画料)への一歩で足が止まる(STG-003、TAC-008) → **転換点が最大の穴**
- ⚠️ 工務店向けDM・小冊子・LPは整備済みだが、送付オペレーションと受け皿の実績提示がこれから

## 1. 戦略 — 「売る」のではなく「参加の階段」を設計する

### 1-1. 基本方針:参加は一段ずつ

哲学(「売り込みより安心の積み重ね」「やさしさを、続けられる仕組みにする」)と整合させ、3者それぞれに**小さなYESを重ねる階段**を用意します。いきなり大きな決断(企画料・契約・家を貸す)を求めない。

```
入居者家族: 小冊子DL → LINE登録 → 暮らし方ワーク → 無料相談 →
            家族会議キット → 有料企画 → 物件提案 → 入居 → 住み継ぎ

工務店:     小冊子DL → 30分オンライン説明 → 収支モデル個別診断 →
            見学(多治見の実案件) → パートナー契約 → 初案件を伴走

オーナー:   空き家健康診断(無料) → 活用シミュレーション →
            「貸す」小さな決断 → 家族とのマッチング
```

### 1-2. 優先順位(今後6ヶ月)

1. **第1優先: 面談→有料企画の転換率改善**(入居者)。新規集客より先に、既に来ている35件+の相談を安心して前に進める導線を整える。ここが直れば、工務店に見せられる「再現可能な型」になる。
2. **第2優先: 工務店の仲間づくり**。多治見での実績(数字と事例)をパッケージ化し、DM+紹介+セミナーで月8〜9社ペースを作る。
3. **第3優先: オーナー開拓の型化**。工務店が地域で使える「オーナー向け提案キット」を用意し、物件供給を家族数に先行させる。

### 1-3. 戦略の一言化

> **「多治見で型をつくり、50社の仲間で全国に写す」**
> エーテルは1000家族を自分で集めるのではなく、「家族が安心して進める型」を完成させて工務店に渡す会社になる。

## 2. 戦術 — 各段の階段を具体化する

### 2-1. 入居者家族:企画料の壁を溶かす4点セット

面談後に止まる理由は資料で特定済みです(①良い物件が見つかるか不安 ②家族に説明できない ③企画料の価値が見えない ④毎月いくら・何年・将来どうなるかのイメージ不足)。それぞれに対策を1つずつ当てます。

| 不安 | 戦術 | 内容 |
|---|---|---|
| ②家族に説明できない | **家族会議キット** | 面談後に持ち帰るA4数枚。仕組み図解+「わが家の場合」の数字+小冊子PART5の暮らし方ワーク簡易版。配偶者が読んで納得できることをゴールに設計 |
| ③企画料の価値が見えない | **企画書サンプルの実物開示** | 過去の企画書(匿名化)を面談で見せる。「これがお渡しする成果物です」と現物で示す。企画料は"物件探し代"ではなく"判断材料一式の制作費"と定義(EXP-006の言語化を流用) |
| ④先が見えない | **ゆずりえシミュレーション1枚** | 面談中にその場で作る「毎月○円 × ○年 → 譲渡」の絵。賃貸継続・新築ローンとの3列比較表 |
| ①本当に見つかるか不安 | **企画料の安心設計** | 「物件候補を1件も提示できなければ企画料は全額返金」等の約束(PHI-004: 返金保証を信頼の約束として使う、と既に言語化済み)。または企画料を着手金+成功時残金の2段階に分割 |

### 2-2. 入居者家族:中間ステップの新設

無料相談と有料企画の間に**「暮らし方整理シート面談(第2回・無料)」**を挟みます。1回の面談で企画料まで進めようとせず、「家族と話してきた結果を一緒に整理する2回目」を標準フローにする。売り込まずに前へ進む哲学と一致し、家族内合意が形成された状態で企画料の話ができます。

### 2-3. 工務店:「儲かる話」ではなく「実例を見に来る話」に

- **多治見モデル見学会(月1回・少人数)**: 実際の再生物件・入居家族(了承済み)・収支の実数を見せる。DMのCTAを「30分オンライン」→「オンライン or 見学会」の2択に。
- **収支モデル個別診断(無料30分)**: DM記載どおり実施。相手の市の空き家数・家賃相場を事前に調べて臨む(プラットフォーム構想のAI・衛星データ抽出をここで先出しに使う)。
- **先着パートナー特典**: 最初の10社は「創業メンバー」として扱い、加盟条件優遇+事例共同発信。50社目標には初期の勢いが不可欠。
- **DM運用の型**: A案(経営者の不安)とB案(家族需要)を業態で出し分け。新築主体の工務店→A案、リフォーム・不動産兼業→B案。5〜7日→7〜10日の3通シーケンスは案の通り。月300社リストを維持(建築新聞・工務店団体名簿・Instagramフォロワーの属性から)。

### 2-4. オーナー:「売る・壊す・放置」以外の選択肢を渡す

- **空き家健康診断(無料)**: 構造・雨漏り・シロアリ・断熱のプロ診断をフックに。診断書は「この家はまだ次の家族に渡せます」という証明書として機能する。
- **オーナー向け1枚提案書**: 「解体費○百万円 vs ゆずりえ活用(家賃収入+管理不要+固定資産税負担軽減)」の比較。工務店パートナーに配布する共通ツールにする。
- **自治体・空き家バンク連携**: プラットフォーム構想にある通り、空き家バンクの「紹介止まり」の穴を埋める実行部隊として自治体に提案。行政連携は後述のPR素材にもなる。

## 3. 宣伝 — 「安心の積み重ね」を発信の型にする

### 3-1. 発信の3層構造

| 層 | 媒体 | 役割 | 頻度 |
|---|---|---|---|
| 出会う | Instagram / 地域フリーペーパー | 「住宅ローンが不安でも戸建てをあきらめない」の一文で見つけてもらう | 週3投稿 |
| 深く知る | 小冊子(入居者向け/工務店向け)+ LP | 不安を一つずつ言葉にして解く。DL時にLINE登録 | 常設 |
| 関係を育てる | LINE公式 / ニュースレター | 売り込まず安心材料を届け続ける(TAC-010の休眠リスト再接触もここで) | 週1配信 |

### 3-2. コンテンツの柱(Instagram/LINE共通)

1. **物語**: 再生前→再生後の家の変化。入居家族の「引っ越した日」の話(1件でも強い)
2. **数字の正直な開示**: 「毎月○円で戸建て、○年で譲渡」のモデルケース。新築ローンとの比較
3. **見極めの裏側**: 「この家は見送りました」という判断の発信。断る基準を見せることが最大の信頼獲得(哲学PHI-009「正直に向き合う」と一致)
4. **人柄**: 伊藤さん自身の「なぜ空き家か」の物語(STG-001の原体験をそのまま使える)

### 3-3. PR(ニュースとして取り上げられる工夫、PRM-009)

- **プレスリリースの切り口**: 「空き家×子育て世帯×住宅ローン不安」は社会課題3点セットで地方紙・NHK地域局が拾いやすい。「多治見発、住み継ぎ100家族プロジェクト始動」のような数字入りの旗を立てる。
- **自治体連携が決まったら必ずリリース**。行政のお墨付きは入居者・オーナー・工務店の3者すべての不安を一度に下げる。
- 工務店50社への最強の宣伝は**「メディアに出ている事業」であること**。PRは入居者向けに見えて工務店開拓の弾になる。

### 3-4. 紹介の仕組み(PRM-008)

- 入居家族に「同じ悩みの友人に小冊子を渡してください」と3冊セットで渡す(金銭謝礼ではなく"仲間を増やす"文脈で。哲学と整合)
- 工務店には「隣接市の同業を1社紹介ください、エリアは重ねません」と依頼。エリア制はそのまま紹介動機になる

## 4. 体験 — 「売り込まれた感覚ではなく、未来が少し見えた感覚」を設計する

整理シート②の言葉をそのまま体験設計のKPIにします。

### 4-1. 入居者家族の体験ハイライト

- **面談の冒頭**: 物件の話をしない。「どんな暮らしがしたいか」から始める(小冊子STEP1と同じ順序。冊子と面談の体験を一致させる)
- **面談の最後(EXP-008: 別れ際の印象)**: 「今日決めなくて大丈夫です。ご家族と話すためのキットをどうぞ」で締める。ピークエンドの法則で「急かされなかった」記憶を残す
- **ゆずりえオープンハウス**: 再生済み物件で開く見学会+暮らし方ワーク体験会。「入居後の暮らし」を五感で体験できる場は、企画料の不安を一気に下げる最強の装置。月1回、Instagram/LINEで告知
- **入居後**: 「家を育てるDIYワークショップ」(棚づくり・壁塗り)を工務店主催で。入居者が発信者・紹介者に変わる仕掛け

### 4-2. 工務店の体験ハイライト

- **見学会で「自分の地域でやれる絵」が見えること**が体験のゴール。収支実数+失敗談も含めて開示する(きれいな話だけだと逆に不信)
- **初案件は伴走**: 契約して終わりではなく、1件目のオーナー打診・建物診断・企画書作成にエーテルが同席。「仲間になったら独りにしない」体験が50社の定着率を決める
- **仲間の場**: 月1回のオンライン事例共有会。PHI-005「未来図を自分の言葉で語れる仲間」を作る場として設計

### 4-3. オーナーの体験ハイライト

- 健康診断の報告書は「あなたの家はまだ生きています」というトーンで。売却査定の「値付けされる体験」との違いを演出
- 入居決定後、**家族からオーナーへの手紙**(任意)を仲介。「家を受け継いでくれる顔が見える」体験は、次のオーナー紹介を生む

## 6. この提案の判断基準(整理シート③に照らして)

- 家族の暮らしに余白を残すか → 企画料の安心設計・2回面談制は「急がせない」を制度化するもの ✅
- 続けられる仕組みか → 無償対応を増やすのではなく、無料と有料の境界を明確にした上で有料の価値を見える化する ✅
- 正直に伝えられているか → 「見送った物件」の発信・失敗談込みの見学会は正直さを競争力に変える ✅
- 住み継ぐ文化を次の世代へ → オーナーへの手紙・DIYワークショップは文化の体験化 ✅
