## 0. 世界観 — 三十カ条が全体の憲法

世界観はすでに完成しています。「もっとやさしく。もっとあたりまえに。」を頂点に、三十カ条の6章がそのまま事業の判断基準になります。本提案では、戦略・戦術・宣伝・体験のそれぞれを三十カ条のどの章が支配するかを明示します。

| 領域 | 支配する章 | 判断基準の要 |
|---|---|---|
| 戦略 | 第1章 声を聞き、未来を見る | 商いは困っている人の声から始める。大家さんを物件提供者として見ない |
| 戦術 | 第2章 安心は、関わり続けることで育つ | 契約してからが本当のお付き合い。資金より先に信用を積む |
| 宣伝 | 第3章 売るより、役に立つことを選ぶ/第6章 未来を贈る住まい方を育てる | 合わない人にはすすめない。提案には相手が次に進める材料を持っていく |
| 体験 | 第4章 地域と仲間に、あたたかな灯りをともす | 関わる仲間を人前で傷つけない。会社の利益と働く人の幸せを切り離さない |
| 全体の逆風時 | 第5章 逆風の中でも、価値を見失わない | 価格を下げる前に価値を伝える。毎日の数字と毎日の心の両方を見る |

**核となる一文**: 「私たちが扱うのは、空き家ではなく、家族の未来です。」
**入居者向けコピー**: 「家賃から、わが家へ。」/「家のために、人生を使いすぎない。」

## 1. 戦略 — 三者の「参加の階段」と、多治見で完成させる型

### 1-1. 競合の定義(戦略共有資料より)

本当の競合は他社ではなく、**「不安で動けない状態」**(無理して新築/賃貸のまま我慢/中古を自己判断)。したがって戦略の中心は「競合に勝つこと」ではなく、**三者それぞれの不安を一段ずつ解いて参加の階段を上ってもらうこと**。

### 1-2. 三者の参加の階段(全資料の仕組みを接続)

```
入居者家族: 発信で出会う → 小冊子(公開フリップブック)を読む → LINE登録 →
            未来の暮らしワークシート → 無料相談(暮らし方ヒアリング) →
            家族会議キットを持ち帰る → 企画支援契約(企画料) → 候補3件+簡易診断A/B/C →
            条件の見える化 → 予約契約 → 改修・入居(定期借家) → 住み継ぎ → 贈与・わが家へ

工務店:     DM/紹介で出会う → 工務店向け小冊子 → 30分オンライン(収支個別診断) →
            多治見モデル見学 → 導入Q&A145問で不安解消 → スターター導入(55万円)
            → 第1回勉強会 → 30日行動計画 → 90日で候補案件 → 1棟目(伴走) → 事例化
            (伴走実践プラン 月額5.5万円は不安が大きい社・加速したい社へ)

オーナー:   工務店パートナーの声かけ/空き家健康診断(無料) →
            「貸しながら活かす選択肢」の提示 → 収支・出口の見える化 →
            金融機関事前相談 → 賃貸活用の決断 → 家族とのマッチング → 手紙・交流
```

### 1-3. 数字の逆算(2026年12月: 工務店50社・入居者1000家族)

- 1000家族 ÷ 50社 = 1社あたり20家族。**工務店の参加が最大レバー**、物件供給(オーナー)が隠れたボトルネック(不変)。
- 導入Q&Aの実務数値で現実性を検証: 1棟=改修400〜600万円・粗利25〜30%・1棟目まで約3ヶ月。**1棟受注で導入費55万円は回収可能** — この回収モデルが工務店営業の背骨になる。
- 加盟ペースは「7〜8月は月3社(型づくり)→秋以降は事例と紹介で加速」の二段ロケット。詳細は工務店開拓計画(別紙)参照。

### 1-4. 優先順位(不変+更新)

1. **面談→企画料の転換率改善**(入居者)— 最大の詰まり。既存ツール(小冊子・ワークシート・実務7ステップ)を導線に組み込んで解く
2. **工務店の仲間づくり** — 価格・提供物・オンボーディング(勉強会→30日→90日)が揃ったので、残りは「営業の実行」と「1号店の事例化」のみ
3. **オーナー開拓の型化** — 30日行動計画の「大家さん声かけ文」+空き家健康診断で、工務店が地域で使える型を標準装備にする

### 1-5. 戦略の一言化

> **「多治見で型を完成させ、三十カ条ごと50社の仲間に渡す」**
> 渡すのはノウハウだけではなく文化。フランチャイズではなく、志を同じくする地域パートナーの連合体をつくる。

## 2. 戦術 — 第2章「安心は、関わり続けることで育つ」を仕組みにする

### 2-1. 入居者家族: 企画料の壁を溶かす(ツールは既に9割ある)

| 不安 | 戦術 | 使う既存資産 |
|---|---|---|
| 家族に説明できない | **家族会議キット**を面談後に持ち帰ってもらう | 小冊子PART5の暮らし方ワーク+未来の暮らしワークシート+「わが家の場合」数字1枚 |
| 企画料の意味が見えない | 企画書サンプル(匿名)を面談で現物開示。「企画料=後悔しない判断材料を整える費用」と定義 | 実務7ステップの成果物一覧(相談記録・候補3件比較表・簡易診断・収支シミュレーション)がそのまま「納品物リスト」になる |
| 先が見えない | その場で「毎月○円×○年→贈与」の3列比較(賃貸継続/新築ローン/ゆずりえ) | 収支シミュレーター |
| 本当に見つかるか不安 | **候補3件方式の事前約束**: 「第一候補=希望に一番近い/第二=バランス/第三=実現性」の3件を必ず提示、提示できなければ企画料返金 | 手順書STEP2の3件方式+PHI-004(返金保証を信頼の約束に) |

**中間ステップの標準化**: 無料相談(1回目)→家族会議→整理面談(2回目・無料)→企画支援契約。第2章六「契約はゴールではない」の通り、急がせない構造を導線そのものに埋め込む。

### 2-2. 工務店: 確定済みパッケージで「誠実な営業」を実行する

- **商談の3点セット**(すべて確定情報で構成可能):
  1. 回収モデル: 「1棟(改修400〜600万・粗利25〜30%)で導入費55万円回収。1棟目まで約3ヶ月」
  2. 役割の正直な開示: 「案件の自動供給はありません。動くのは御社、本部は型と伴走」(導入Q&A Q11〜Q20をそのまま話す)
  3. **向かない会社の明示**(Q115): 丸投げ・短期売上のみ・地域に関心がない会社には向かない、と先に言う。第3章十一「合わない人にはすすめない」の実践であり、最強の信頼獲得
- **不安への回答は導入Q&A145問に集約済み**。営業担当は暗記ではなく「Q&Aを一緒に開く」スタイルで面談する(第2章七「不安や疑問は信頼を深める入口」)
- **オンボーディングは既存プログラムに接続**: 契約→第1回勉強会→30日行動計画(説明できる/導線がある/リスト30件/候補1件/次の約束)→90日で1棟目。加盟後の初動が設計済みであること自体を営業材料にする
- **エリア方針の決定が残タスク**(1市1社にするか)。決めれば「御社の市を他社に案内する前に」という誠実な限定性が使える

### 2-3. オーナー: 「売る・壊す・放置」の外側にある選択肢を渡す

- 声かけの型は30日行動計画とパートナーQ&Aに既にある: 「貸してください」ではなく**「可能性を一緒に確認しましょう」**(Q10: 「簡単に儲かる」とは絶対に言わない)
- **空き家健康診断(無料)**: 構造・雨漏り・シロアリ・断熱の見極め6項目を診断書に。「あなたの家はまだ次の家族に渡せます」という証明書として機能させる
- 収支・出口(定期借家→満了→贈与、税・登記)を実務フロー2に沿って最初に見える化。**専門家確認5点(宅建業法・定期借家整合・融資抵当権・贈与税・不履行時)は50社展開前に本部で潰し、「専門家確認済みスキーム」として全パートナーに配る** — オーナー・金融機関・工務店の三方の不安を一度に下げる最重要投資

### 3-2. コンテンツの柱

1. **物語**: 再生前→後の家、入居家族の「引っ越した日」。「小さな物語・佐藤さん一家」(小冊子)のトーンを発信にも展開

3. **見極めの裏側**: 「この家は見送りました」という判断の発信。見極め6項目を見せる=誠実さの証明(第1章四「見た目の立派さより、誠実な中身」)
4. **暮らしの参加権**: 菜園の家・縁側の家・火を囲める家・土間の家。物件ごとの「生きている手ざわり」を発信の差別化軸に
5. **人柄と原点**: 伊藤さんの「なぜ空き家か」(STG-001の原体験)

- メディア掲載は入居者向けに見えて、**工務店開拓とオーナー・金融機関の信用に最も効く**

### 3-5. 紹介の仕組み

## 4. 体験 — 「売り込まれた感覚ではなく、未来が少し見えた感覚」

### 4-1. 入居者家族の体験

- **面談は物件の話から始めない**。未来の暮らしワークシート(15問)で「10年後20年後のわが家の物語」から入る — 小冊子STEP1と同じ順序で、読む体験と会う体験を一致させる
- **面談の別れ際**(EXP-008): 「今日決めなくて大丈夫です。ご家族と話すためのキットをどうぞ」で締める。持ち帰るものがある面談にする
- **ゆずりえオープンハウス**(月1回): 再生済み物件で「暮らしの参加権」を五感で体験(壁の色を選ぶ疑似体験・菜園・土間の使い方)。企画料の不安を一気に下げる最強装置
- **入居後**: 「家を育てるDIYワークショップ」「年1回の住まい点検」「家族イベント」(手ざわり資料の伴走メニュー)。入居者が発信者・紹介者に変わる

### 4-2. 工務店パートナーの体験

- **加盟前**: 個別収支診断(相手の市の空き家数・相場を調べて臨む)=「自分の街を調べてくれた」体験。向かない条件も正直に言う
- **加盟直後**: 第1回勉強会→30日行動計画で「独りにしない」を制度化。30日後に「説明できる・相談が来る・候補がある」状態を保証する設計
- **1棟目**: オーナー打診・建物診断・企画書作成に本部が同席(事前ロープレ込み、パートナーQ&A Q6の型)。Q42「最初の1棟は無理な物件を選ばず、成功事例として残す」
- **仲間の場**: 月1回オンライン事例共有会。第4章十七「協力会社に感謝し、必要なことは誠実に伝える」を体現する場。創業10社は「創業メンバー」として名を刻む
- **パートナー4つの心得**(誠実に伝える/無理に進めない/専門家と連携する/地域で信頼を育てる)を勉強会の冒頭に必ず置く=文化ごと渡す

### 4-3. オーナーの体験

- 健康診断の報告書は「値付けされる体験」ではなく「家がまだ生きていると証明される体験」に
- 入居決定後、家族からオーナーへの手紙(任意)を仲介。「受け継いでくれる顔が見える」— 第1章五「大家さんを、単なる物件提供者として見ない」の体験化
- 満了・贈与の日は「引き渡し式」として小さく祝う(写真はPR素材にも)
