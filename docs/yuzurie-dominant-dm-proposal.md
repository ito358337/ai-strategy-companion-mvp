# 工務店募集DM ドミナント戦略版 改善提案

作成日: 2026年7月2日
背景: 既存DM(A案/B案)をメール送付したが反応が出ていない → ドミナント戦略の考え方でDMを再設計する

---

## 1. まず現状の診断 — 「反応ゼロ」は文面だけの問題ではない

調べた相場観と照らすと、原因は3つに分解できます。

### 診断① そもそもコールドメールの返信率は1%未満が相場

面識のない相手への営業メールの平均返信率は1%未満〜数%、開封率も15〜25%程度が相場。つまり**50〜100社への送付で返信ゼロは統計的に「普通」**であり、文面が悪い証拠にはならない。ただし件名とパーソナライズ次第で返信率10%台まで上げているチームも存在する。

### 診断② 建設業界はメールが届きにくい業界

工務店の経営者は日中現場に出ており、メールは事務スタッフ止まりになりやすい(現行文面が「窓口ご担当者様→代表者様へご回覧ください」と二段構えなのはこの弱点の自己申告でもある)。建設業界ではいまだに**FAXが現役の連絡手段**で、FAX DMは「開封率100%(届けば必ず紙で見える)」・反応率0.3〜0.5%が相場。電話フォローとの組み合わせで成約率が上がるとされる。

### 診断③ 現行文面は「全国どこでも同じ話」になっている

A案/B案とも内容は良いが、受け取った社長から見ると「うちの市の話」ではない。**一般論の提案は後回しにされ、自分の商圏の話は読まれる。** ここがドミナント戦略で変えられる最大のポイント。

---

## 2. ドミナント形式に変えると何が変わるか

ドミナント戦略をDMに落とすと、訴求が3段階で具体化します。

| 現行 | ドミナント版 |
|---|---|
| 「全国の工務店様へ、第3の集客導線のご案内」 | **「〇〇市で、この仕組みを担う1社を探しています」** |
| 空き家が増えている(一般論) | **「〇〇市の空き家は約△△戸(令和5年住宅・土地統計調査)」**(実数) |
| いつでも誰でも加盟できる | **1市1社。枠が埋まれば同市には案内しない**(テリトリー保護はFC加盟募集で「大きな安心材料・有力なセールストーク」とされる定石) |
| 多治見の実績の紹介 | **「隣の◇◇市では既に動き始めています」**(同心円で埋めるからこそ書ける近接の証拠) |

ポイントは、**限定性が「煽り」ではなく事実になる**こと。1市1社のエリア制を本当に採用すれば、「御社の市を他社にご案内する前に、まず地域で信頼のある御社に」という文面は誠実な順番の説明になり、三十カ条(合わない人にすすめない・正直に伝える)と矛盾しない。

### 送る順番も「ドミナント」にする

リストを全国に散らさず、**多治見を中心に同心円で送る**: ①東濃(多治見・土岐・瑞浪・恵那・中津川)→②岐阜県内→③愛知・長野・三重→④その先。
効果: (a)見学会に呼べる距離 (b)「隣の市で始まった」という近接の社会的証明が本当になる (c)取材・紹介・職人ネットワークが重なる。

### 現行版からの変更点(なぜ効くか)

1. **件名に市名と実数** — 「自分の商圏の話だ」と分かる件名は開封率を大きく左右する(パーソナライズが返信率改善の第一要素)
2. **1社限定を冒頭に** — テリトリー保護はFC募集の定石の安心材料。読み飛ばされる前に希少性を伝える
3. **CTAを2段に下げる** — 「30分オンライン」はコールドの初回には重い。「返信だけで市のデータ1枚が届く」に下げ、返信のハードルを最小化
4. **「向いていない会社」を明記** — 導入Q&A Q115の内容。正直さがそのまま差別化になる(三十カ条第3章)
5. **回収モデルを数字で1行** — 400〜600万円・1棟で回収(導入Q&Aの確定数値)

※△△戸は e-Stat「令和5年住宅・土地統計調査」の市区町村別空き家数から転記。リスト作成時に1列追加するだけで全メールが「その市の話」になる。

## 4. チャネルの追加 — メールだけで戦わない

| チャネル | 使い方 | 期待値 |
|---|---|---|
| メール(改訂版) | 上記ドミナント版を3通シーケンスで(間隔は現行どおり5〜7日/7〜10日) | 返信率1〜3%を目標 |
| **FAX DM** | 同じ内容をA4・1枚に圧縮(市名・空き家数・1社限定・QRコード2つ=小冊子/返信フォーム)。現場中心の業界でメールより社長の目に届きやすい | 反応率0.3〜0.5%が相場。メールと併用で接触率を底上げ |
| 電話フォロー | メール/FAX送付の3〜5日後、反応のない先へ「資料は届きましたか、〇〇市の空き家データだけでもお送りします」と一言 | FAX+電話の組み合わせは成約率を上げる定石 |
| 紹介・建材店ルート | 変更なし(最も確度が高い経路として継続) | 面談→契約5割超 |

**運用イメージ(週次)**: 月曜=メール1通目50社(1市ずつ)→水曜=同じ市にFAX→翌週=未反応先へ電話→反応者は「市の1枚資料」→30分面談 or 少人数勉強会へ。

- 各波の中でも「空き家数が多い×人口減少が緩い」市を優先(空き家は多いが入居需要も残っている市がゆずりえの成立条件に合う)
- 1市が決まるたびにInstagram/LINEで「〇〇市のパートナーが決まりました」と発信 → 隣接市への最強のFAXネタ・メールネタになる(ドミナントの自己増殖)
