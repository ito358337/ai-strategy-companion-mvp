# ゆずりえパートナー 加盟のご案内

**家賃から、わが家へ。** — 空き家を見極め、整え、若いご家族が住みながら将来「わが家」へ近づいていく、第三の住まい方。それが「ゆずりえ」です。

---

## 1つの市に、1社だけ

- ゆずりえは、**1つの市につきパートナー工務店を基本的に1社だけ**置きます
- 空き家の見極めも、大家さんとの信頼も、入居後の暮らしの相談も、その市に根を張った1社が担うのが、いちばん誠実に回るからです
- 御社の市で「空き家と住まいの相談なら、あの会社」と呼ばれるのは、1社だけです

## 加盟したら、お渡しするもの

多治見で実際に使っている一式を、御社の市の仕様にしてお渡しします。

- 若いご家族に届ける**小冊子**/**ストーリー漫画**「うちは、まだ潰れていないだけだった。」
- 暮らしの希望を聞き取る**未来の暮らしワークシート**
- 想定質問**145問の導入Q&A**+加盟後の実務Q&A
- **契約書の雛形**(定期借家・停止条件付贈与など)
- **収支シミュレーション**の型
- **30日行動計画書**+第1回勉強会
- **1棟目までの伴走**(オーナー様への打診・建物診断・企画書づくりに同席します)

## 数字は、正直にお伝えします

| 項目 | 目安 |
|---|---|
| 改修規模 | 1棟あたり400〜600万円(物件により300万円台〜800万円超) |
| 工務店の粗利 | 25〜30%目安(相見積もりの価格競争ではなく、見極めと提案に価値がつく仕事です) |
| 最初の1棟まで | 約3ヶ月 |
| スターター導入 | **55万円(税込)** — 1棟の受注で回収できる設計です |
| 伴走実践プラン | **月額5.5万円(税込)** — 発信改善・相談整理まで毎月一緒に回したい会社向け。自走できる会社はスターターのみで始められます |

- 参考実績: 多治見市にて、広告費をほとんどかけず**2ヶ月で35件以上のご相談**(2026年6月時点)
- ※成果を保証するものではありません。案件の自動供給はなく、地域で動く主役は御社です

## 先に、正直に申し上げます

**向いていない会社**: 短期の売上だけを求める会社/本部に丸投げしたい会社/地域との関係づくりに関心のない会社

逆に言えば——地域で長く信頼を積み、職人の腕に誇りを持つ会社にこそ、お渡ししたい仕組みです。

## 加盟までの流れ

**① 30分オンライン**(御社の市の空き家データと可能性を一緒に確認)→ **② 少人数勉強会** → **③ 契約** → **④ 第1回勉強会+30日行動計画スタート**

※契約・税務・融資・宅建業法に関わる部分は、専門家確認を前提に物件ごとに丁寧に整えます。
