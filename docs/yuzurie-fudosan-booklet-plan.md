# 不動産会社向け小冊子 企画案
## 「売れない預かり物件の、新しい出口」を1万字の本にする

作成日: 2026年7月8日
対象読者(N1): 地元不動産会社の営業課長・店主(40〜55歳)。店の奥に「売れない・貸せない古家の預かり物件」が眠っている人
分量: 約10,000〜11,000字(読了20分。heyzineフリップブック+印刷A5冊子を想定)
シリーズ内の位置づけ: 工務店向け「工務店経営者よ、その不安は『空き家』が解決する！」の姉妹編。これで3者向けツールが揃う(入居者=小冊子7-1/工務店=漫画+小冊子/不動産・大家=本書)

## 1. タイトル案(5案)

| # | タイトル | 狙い |
|---|---|---|
| ★1 | **「その物件、断らなくていい。」— 売れない預かり物件に"四つ目の出口"をつくる本** | 推奨案。営業課長の日常の痛み(「売れません」と言う瞬間)を一撃で突く。⑧保身&安全→③平穏 |
| 2 | 「塩漬け物件が、店の看板に変わる。」— 地域で選ばれる不動産会社の新しい武器 | ①承認&優越に振った案。攻めの店主向け |
| 3 | 「不動産会社よ、その"売れない物件"は宝かもしれない。」 | 工務店版とシリーズ感を揃える案。既存読者に統一感 |
| 4 | 「『更地にして売却』しか言えない店に、しないために。」 | 問題提起型。刺さるが、やや攻撃的なので候補次点 |
| 5 | 「預かり物件、眠らせておくには惜しすぎる。」— 仲介の立場のまま始める空き家活用 | 穏やか版。手紙同封など出会いの温度が低い場面用 |

推奨は**案1**。理由: 不動産会社のN1が一番よく口にする言葉が「これは難しいですね(=断り)」であり、「断らなくていい」はその日常を直接ひっくり返す言葉だから。サブタイトルの「四つ目の出口」は大家向けメッセージ(売る・壊す・放置じゃない四つ目)と対になり、オーナーへの説明にそのまま転用できる。

## 2. 本書の芯(1行)

> **御社は、仲介の立場のまま。建物の見極めと改修と入居後は、こちらが持つ。売れない物件に、堂々と提案できる出口を。**

読者が本書で買うもの: 新しい収益源(表向き)ではなく、**「オーナーに『できません』と言わなくて済む店になる」という誇りと安心**(本音)。

## 3. 構成原案(全7章+はじめに・おわりに/約11,000字)

### はじめに|店の奥で眠っている台帳の話(約800字)
夕方の店内。今日も1本、実家を相続した人からの相談電話。「築40年、駅から遠い、再建築は微妙」——査定するまでもなく、売れないと分かってしまう。「更地にして売却ですかね」と言った瞬間の、電話口の沈黙。あの沈黙、覚えがありませんか。この本は、その沈黙に「もうひとつの答え」を持てるようになる本です。
※工務店版の「夜の事務所」と対になる情景で開く。

### 第1章|「売れません」と言うたびに、店が失っているもの(約1,500字)
- 断った相談は、オーナーごと他店(または放置)へ消える
- 失っているのは仲介手数料1件分ではない: ①オーナーとの長期の関係(その人の自宅・相続・買い替えまで全部) ②「あの店に聞けば何とかしてくれる」という地域の評判 ③店の奥の台帳に積み上がる"心理的な負債"
- 一方で、古家の相談は今後も増え続ける(空き家約900万戸・今後も相続で増加)。**断る技術ではなく、受ける仕組みが要る時代**

### 第2章|なぜ、あの物件は動かないのか(約1,500字)
- 売買前提の構造的な限界: 価格が付かない/再建築・接道の問題/買い手のローンが付かない/仲介手数料が安すぎて動けない
- 賃貸に回そうにも: 現況では貸せない/改修費を誰が出すのか/オーナーは決断できない
- つまり「売る」「貸す」の二択の間に、**建築の判断(直せるか・いくらか・住み継げるか)が丸ごと抜けている**。不動産会社が悪いのではなく、建築のプロが隣にいなかっただけ

### 第3章|四つ目の出口「ゆずりえ」とは(約2,000字)
- 仕組みの説明: 空き家を工務店が見極め・改修し、若い家族が定期借家で住みながら、約束の期間の先に贈与・譲渡で「わが家」へ近づく
- **需要は実在する**: 「戸建てに住みたいが35年ローンが怖い」子育て世帯。多治見で広告費ほぼゼロ・2ヶ月35件以上の相談(2026年6月時点)
- オーナーにとっての意味: 売却でも解体でもなく「家賃収入を得ながら、家の行き先が決まる」
- 誠実さの明示: どんな物件でもできるわけではない(簡易診断A/B/Cで見極める)。「この物件は見送りましょう」と言える仕組みであること

### 第4章|御社の役割は、変わらない(約2,000字)★本書の心臓部
- **役割分担表**を中央に置く:
  - 不動産会社: オーナー窓口・媒介・重要事項説明・契約実務(=宅建業の独占業務はすべて御社)
  - 工務店(ゆずりえパートナー): 建物診断・改修費概算・改修工事・入居後の点検
  - ゆずりえ本部: 仕組み・契約雛形・収支シミュレーションの型・専門家確認の考え方
- 報酬の透明性: 御社の仲介報酬はこれまで通り。加えて塩漬け物件が「動く物件」に変わる
- 法務への配慮: 定期借家・停止条件付贈与などは司法書士・税理士・弁護士の確認を前提に物件ごとに整える(=御社の看板を汚さない設計)
- **「取られる」不安への先回り**: ゆずりえは不動産業に参入しない。建築側の仕事(見極め・改修)を担うだけ。むしろ宅建業務は御社にしかできない

### 第5章|進め方は、台帳から1件選ぶだけ(約1,200字)
- STEP1: 店の奥の「動いていない預かり物件」から1件だけ選ぶ
- STEP2: 無料の簡易診断(建物・改修概算・想定家賃)をこちらで実施→A/B/C判定を報告
- STEP3: A判定なら、オーナーへの提案に同席(説明資料はこちらが用意、話すのは御社でもこちらでも)
- STEP4: 入居希望家族とのマッチング→契約(媒介は御社)
- 「まず1件、腕試しのつもりで」——小さく始める設計を明記

### 第6章|よくあるご質問(約1,200字)
導入Q&A145問から不動産会社向けを抜粋・翻案(Q82・Q89・Q90ほか):
1. 責任の所在は?(建物の瑕疵は建築側、契約実務は御社、と線を引く)
2. オーナーにどう説明すればいい?(説明資料と「四つ目の選択肢」トークを提供)
3. 手数料はどうなる?(媒介報酬は従来通り+具体の取り決めは個別に明確化)
4. 入居者は本当にいるのか?(35件の実績と入居希望者の声)
5. 途中でトラブルになったら?(滞納・中途退去・相続発生時の取り決めを契約前に整える)

### おわりに|「断らない店」が、地域の灯りを増やす(約800字)
「売れません」の代わりに「実は、四つ目の出口があるんです」と言える店。オーナーの肩の荷が下り、若い家族に住まいが生まれ、御社には関係と評判が残る。
締めの一文: **家は、家族を縛るものではなく、家族の未来を守るもの。その循環の入口に、御社の店がなってくれたら嬉しいです。**
CTA: 「動いていない預かり物件、1件だけ聞かせてください」— 無料の物件持ち込み相談(30分)+QRコード

- 工務店版・入居者版と同じ世界観(三十カ条)。ただし読者はプロなので、**情緒は薄め・実務と数字は濃いめ**に配合を変える
