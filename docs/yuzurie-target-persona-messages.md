# ゆずりえ ターゲット設定と「伝え続ける言葉」
## 入居者・大家さん(不動産会社含む)・工務店 3つの目線

作成日: 2026年7月8日
考え方の元: OZA SODAの教訓 — 万人に売ろうとするほど誰にも刺さらない。**「たった一人」を決め、その人に向けた言葉と見せ方を、変えずに発信し続ける。** 絞ることは他を捨てることではない。一人に深く刺さる言葉が、周りを巻き込む。

---

## 全体の設計原則

1. 各ターゲットに**「N1(たった一人)」**を名前つきで決める。発信・資料・面談トークはすべて「その人が読んだらどう感じるか」で判断する
2. **コアの一言は変えない。** OZA SODAが「30〜40代女性の視点」を貫いたように、ゆずりえも同じ言葉を1年間言い続ける(飽きるのは発信側が先。受け手はまだ知らない)
3. 絞っても捨てない構造を先に確認する: 妻に刺されば夫と両親が巻き込まれる。相続した長男に刺されば兄弟と不動産会社が巻き込まれる。2代目社長に刺されば職人と同業が巻き込まれる

---

## 1. 入居者目線(27〜40歳)

### N1: 「さくらさん」32歳
小冊子の「佐藤さん一家」の奥さんに名前を付けて、社内共通のN1にする。

- 32歳・パート勤務。夫34歳(会社勤め)。子ども2人(4歳・1歳)
- 家賃6.5万円の2LDKアパート。おもちゃを広げるとリビングがいっぱい。下の階に気をつかい「走っちゃだめ」と言ってばかり
- 世帯年収450万円前後。教育費と将来のお金が心配で、35年ローンが怖い
- 情報行動: 夜、子どもを寝かせた後にInstagramで「おうちアカウント」を眺める。決断は夫婦だが、**住まい探しの起点は妻**
- 買っているのは「家」ではなく、**家族の時間と心の余白**

### なぜ夫(34歳)ではなく妻(32歳)に絞るか
楽天の主婦層と同じ構図。住まいの情報収集・共有・家族会議の起点は妻であることが圧倒的に多い。妻に刺されば、家族会議キットが夫と両親を巻き込む。夫起点の言葉(金利・資産性)は妻には刺さらず、妻起点の言葉(暮らしの場面)は夫にも刺さる。

### 伝え続ける言葉
- **コアの一言(変えない)**: 「家賃から、わが家へ。」
- 支える言葉(ローテーション):
  - 「うちみたいな家族でも、戸建てをあきらめなくていい」
  - 「『走っちゃだめ』と言わなくていい家へ」
  - 「家を買う、でも、ずっと借りる、でもない。第三の住まい方」
  - 「家のために、人生を使いすぎない」
- 見せ方: スペックや価格ではなく**暮らしの場面**(庭で走る子ども・菜園・土間・壁の色を選ぶ家族)。佐藤さん一家の物語のトーンで
- 刺している欲望: ⑦守りたいものがある(核)・③心身平穏・②無理のない自由

### 言ってはいけない言葉
「激安」「訳あり物件」「掘り出し物」「投資」「今だけ」——さくらさんが求めているのは安さではなく安心。煽りは三十カ条にも反する

### 主な接点
Instagram(夜21〜23時投稿)・LINE・オープンハウス・小冊子。CTAは常に「今日決めなくて大丈夫。まずは暮らしのおしゃべりから」

## 2. 大家さん目線(45〜60歳)+仲介の不動産会社

### N1: 「孝さん」58歳
- 会社員(定年まであと数年)。3年前に父を亡くし、**多治見の実家を相続**。今は空き家
- 自分は隣市に持ち家。実家には盆と彼岸に風を通しに行く。庭の草が伸びるたびに心が重い
- 「売れば?」と言われるが、**親父の建てた家を壊すのも、二束三文で手放すのも嫌だ。** でも管理はもう限界
- 不動産会社に相談したら「更地にして売却が一番」と言われ、それきり足が向かない
- 買っているのは「家賃収入」ではなく、**親の家の行き先への納得と、肩の荷が下りる安心**

### なぜ「貸したい人」ではなく「決めきれない人」に絞るか
すでに貸す気の大家さんは市場に出ており競争になる。ゆずりえの独壇場は「売る・壊す・放置のどれも選べずに止まっている人」——本当の競合は"不安で動けない状態"、の大家さん版。

### 伝え続ける言葉
- **コアの一言(変えない)**: 「その空き家、宝かもしれません。」
- 支える言葉:
  - 「壊さずに、想いごと次の家族へ」
  - 「あなたの家が、また誰かの人生の舞台になる」
  - 「売る・壊す・放置、じゃない**四つ目の選択肢**」
  - 「まだ出番を待っている家、ありませんか」
- 見せ方: 査定額ではなく**「家がまだ生きている証明」**(空き家健康診断書)と、入居家族からの手紙の実例
- 刺している欲望: ⑩愛&感動(核)・⑦家の記憶を守る・③管理の平穏

### 併走ターゲット: 仲介の不動産会社(営業担当・40〜50代)
- N1: 地元不動産会社の営業課長。**「売れない・貸せない古家の預かり物件」が店の奥で寝ている**
- 伝え続ける言葉: 「**売れない預かり物件の、新しい出口**を一緒に」「オーナーさんに『四つ目の選択肢』を提案できる店になりませんか」「建物の見極めと改修はこちらが担当。御社は仲介の立場のままで」
- 刺しどころ: 塩漬け案件が動く+オーナーとの関係が守れる+報酬はきちんと入る(役割と分け前を最初に明確に)

### 言ってはいけない言葉
「簡単に儲かります」「不労所得」「相続対策」(パートナーQ&A Q10の教えの通り。誠実さだけが孝さんを動かす)

### 主な接点
手紙(手書き宛名)・地域紙・空き家健康診断(無料)・不動産会社/自治体からの紹介・お寺や地域の集まり

## 3. 工務店目線(38〜55歳)

### N1: 「誠さん」45歳・2代目社長
- 従業員8名(大工3人は60代)。父から継いで12年
- 新築が年6棟→2棟に。リフォームは相見積もりで粗利が薄い。広告費は上がる一方
- 夜、事務所で一人、売上のグラフを眺める。「今日の仕事はある。でも5年後の柱が見えない」
- 息子は中学生。継がせられる会社にできるのか、それすら分からない
- 買っているのは「新規事業」ではなく、**会社と職人を守れる次の柱と、地域で必要とされ続ける誇り**

### なぜ「多角化に積極的な社長」ではなく「不安を抱えた2代目」に絞るか
勢いのある会社は他のFCにも口説かれており競争になる。ゆずりえが一番深く刺さるのは、**地域で信頼はあるのに次の一手が見えない会社**——漫画の主人公そのもの。そして誠さんに刺されば、職人・協力業者・同業の仲間が巻き込まれる。

### 伝え続ける言葉
- **コアの一言(変えない)**: 「うちは、まだ潰れていないだけだった。」(入口) →「〇〇市で"空き家ならあの会社"と呼ばれる1社に。」(出口)
- 支える言葉:
  - 「新築の次の柱を、市内の空き家△△戸に」
  - 「1つの市に、1社だけ」
  - 「花火ではなく、街灯を。」
  - 「守りたい家族がいて、活かされていない家がある。つなぐのは、御社の腕」
- 見せ方: 不安への共感(3行まで)→誇りの出口。実数(改修400〜600万円・1棟目まで約3ヶ月・多治見の相談実績)を正直に。「向いていない会社」も先に言う
- 刺している欲望: ⑧保身&安全(入口)→⑦会社と職人を守る・①地域での承認(出口)

### 言ってはいけない言葉
「儲かるフランチャイズ」「不労収入」「誰でもできる」——誠さんは楽な話を信じない。楽な話に一番警戒心が強い人だからこそ、正直さが唯一の通行証

### 主な接点
郵送の手紙3通(38社)・工務店向け小冊子/漫画・少人数勉強会(3〜5社)・建材店/金融機関からの紹介

## 4. 3者共通の背骨(1枚で見る)

| | 入居者: さくらさん32歳 | 大家: 孝さん58歳(+不動産会社) | 工務店: 誠さん45歳 |
|---|---|---|---|
| 止まっている理由 | 35年ローンが怖い | 売るも壊すも決めきれない | 次の柱が見えない |
| 本当に買うもの | 家族の時間と余白 | 親の家の行き先への納得 | 会社と職人を守る誇り |
| コアの一言 | 家賃から、わが家へ。 | その空き家、宝かもしれません。 | うちは、まだ潰れていないだけだった。 |
| 刺す欲望 | ⑦守りたい・③平穏 | ⑩愛&感動・③平穏 | ⑧保身→⑦⑪誇り |
| 巻き込まれる周辺 | 夫・両親・ママ友 | 兄弟・不動産会社・自治体 | 職人・協力業者・同業 |
| 接点 | Instagram・LINE・オープンハウス | 手紙・健康診断・紹介 | 手紙3通・勉強会・紹介 |
| 禁句 | 激安・訳あり・投資 | 儲かる・不労所得 | 儲かるFC・誰でもできる |

**共通の禁則**: 3者に同じ文章を使い回さない(万人向けの言葉に戻ってしまう)。ただし世界観の一文——「家は、家族を縛るものではなく、家族の未来を守るもの」——だけは3者すべてに共通で置いてよい。これが「絞っても、ひとつのゆずりえ」を保つ背骨になる。

## 5. 運用ルール(OZA SODA式)

1. 発信物を作ったら、投稿前に**「さくらさん/孝さん/誠さんが読んだら?」**と1回だけ自問する(社内チェックはこの1問だけでいい)
2. コアの一言は**最低1年間変えない**。反応が落ちたら支える言葉の方を入れ替える
3. 月次レビューで「どのN1向けの発信が何本だったか」を数える。**さくらさん向けが0本の月を作らない**(現状の詰まり=面談→企画料はさくらさん側の導線)
