## 既存提案への反映メモ(次回更新時に織り込む)

1. **「本当の競合は不安で動けない状態」**(資料8)は、宣伝コピー・面談トーク・LPの軸に据える。競合他社比較ではなく「動けない理由」を一つずつ解く構成に。
2. **「暮らしの参加権」と物件4タイプ**(資料7)は、入居者向け宣伝の差別化コンテンツ・オープンハウスの体験メニューとしてそのまま使える。工務店向けには「加盟後の継続収益メニュー」(DIY講座・年1点検・ワークショップ)として提示できる。
3. **三十カ条**(資料6)は、加盟工務店の研修教材・行動規範に最適。「加盟パッケージ」の提供物に含める(仕組みだけでなく文化ごと渡す=フランチャイズとの差別化)。
4. **実務7ステップ+実務フロー2**(資料9・10)により、工務店に渡す「型」は既にほぼ文書化済み。加盟パッケージの中身は「三十カ条(文化)+手順書(実務)+実務フロー(契約)+小冊子・DM(集客)」の4点で構成できる。
5. **専門家確認ポイント5つ**(資料10)は未解決リスクとして扱う。特に宅建業法・定期借家・贈与税は、50社展開前に弁護士・税理士・宅建士の確認を済ませ、「専門家確認済みスキーム」として加盟営業の安心材料に転換する。
6. 面談→企画料の詰まり対策(既提案の家族会議キット等)は、資料8の「まず整える3つ(資料・導線・言葉)」と同一方向で整合済み。
