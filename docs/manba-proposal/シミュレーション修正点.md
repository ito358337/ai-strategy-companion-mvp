# 中川区万場 戸建賃貸プロジェクト — シミュレーション検証・修正点まとめ

2026年7月8日付「概略事業計画（☆資金計画）」シートの検証結果です。
修正反映済みの完全版事業計画書は同フォルダの `index.html` を参照してください。

## 検証でOKだった点

- **返済額の計算は正確**: 借入6,425.2万円・変動1.5%・22年 → 月285,893円（再計算と一致）
- **単純利回り7.38%**: 474万円 ÷ 6,425万円で計算どおり
- **担保評価の積算ロジック**: 路線価×80%＋建物×70%は一般的な銀行積算と整合

## 修正した5つの問題点

### ① 運営経費・空室損が未計上（最重要）
- 元シートの「手取り109,107円/月」は管理料・固定資産税・保険・修繕・空室がすべてゼロの前提。
- **修正**: 空室5%＋管理料5%＋固都税42万円（軽減後）＋保険10万円＋修繕15万円＋雑費3.6万円を計上。
- 安定期NOI（営業純利益）= **年357.2万円**（NOI率 約79%）

### ② 「実質利回り2.04%」の定義が不適切
- 元シートの2.04%は「返済後手取り ÷ 総投資額」でフルローン時のCF利回り。金融機関・投資家の見る指標ではない。
- **修正**: 実質（NOI）利回り = 357.2万円 ÷ 総事業費6,704万円 = **5.33%**。返済余力はDSCRで別掲。

### ③ 減価償却の償却率が誤り
- 元シート: 39,503,640円 × 0.038 = 年1,501,138円（0.038は耐用年数27年の率）。
  脚注の1,975,182円（率0.050 = 20年）とも不整合。
- **修正**: 木造住宅用は法定耐用年数**22年・償却率0.046** → **年1,817,167円**。
  節税効果は元シートより年約31万円大きくなる（納税側に不利な誤りではないが、銀行提出資料としては要修正）。

### ④ 「別途」費用9項目が未計上
概算で **+279万円** を計上し、総事業費を 6,425万円 → **6,704万円** に是正:

| 項目 | 概算 |
|---|---:|
| 土地仲介手数料（3%+6万円＋税） | 759,000円 |
| 登記費用（移転・表示・保存） | 670,000円 |
| 抵当権設定費用 | 360,000円 |
| 期中利息（2%・工期5ヶ月） | 400,000円 |
| 融資事務手数料・保証料等 | 600,000円 |
| 不動産取得税 | 実質0円（新築賃貸住宅の1戸1,200万円控除適用見込み） |

※火災保険は初期費用でなく運営費（年10万円）に計上して二重計上を回避。

### ⑤ 融資判定「不可」のまま放置
- 積算担保4,236万円 < 必要資金6,425万円（不足2,189万円）で判定が「不可」のまま提出される状態だった。
- **修正**: 3点セットで保全を再構成
  1. **収益還元評価の併記**: NOI 357.2万円 ÷ Cap 6.5% = **5,495万円**
  2. **自己資金1,000万円の投入**（推奨シナリオB）
  3. 保証会社保証（元計画に保証料計上済み）の明示
